# AI-generated Aspect Foci asset import

The user corrected the art direction: new Foci should use image generation rather than code-first/manual drawing.

This folder stores the generated image sources, prompts, and import previews. The actual shipped textures under `src/main/resources/assets/attuned/textures/item/` were rebuilt from these AI concept sheets by automated crop/matte/downscale/pulse processing, not by hand-drawing the icon motifs.
